# Description: Enhance and unify the existing LangGraph architecture to serve as the unified backend orchestration engine for the SpaceLive platform, building upon the current implementation.
# Details:
Enhance the existing LangGraph architecture in `/prototype/backend/services/ai/dialogue_graph.py` and related modules to create a unified orchestration system with the following improvements:

1. Complete the ongoing modularization refactoring:
   - Finalize migration from `services/ai/` to specialized modules like `services/dialogue_manager/`
   - Ensure clean interfaces between modules

2. Enhance and standardize core node types:
   - Integrate existing nodes from `/prototype/backend/services/ai/graph_nodes/`
   - Extend with additional required nodes:
     - `TimeTriggerNode`: For schedule-based triggers
     - `StateMonitorNode`: For monitoring character state and idle time
     - `UserInputNode`: For processing user inputs
     - `SchedulerNode`: For managing scheduled tasks
     - `LLMInterfaceNode`: For LLM API calls (enhance existing)
     - `MemorySystemInterfaceNode`: For memory read/write operations (enhance existing)
     - `EmotionAnalyzerNode`: For analyzing text emotions

3. Unify flow differentiation:
   - Implement simplified path for real-time dialogue
   - Implement complex path for scheduled tasks with tool invocation
   - Enhance existing murmur_service for spontaneous dialogue flow

4. Improve state management:
   - Design shared state structure for all behavior types
   - Implement robust state persistence mechanism
   - Ensure state sharing across different flow types

Build upon the existing Python with FastAPI backend framework. Ensure the architecture remains modular and extensible to accommodate future tools and functionalities. Focus on iterative development with functional milestones at each stage.

# Test Strategy:
1. Manual testing of each component as it's developed
2. Integration verification when connecting components
3. Basic functionality validation for each milestone
4. Performance checks to ensure response times meet requirements (<1.5s for real-time dialogue, <3s for scheduled tasks)
5. Use simple mocks for external dependencies during development
