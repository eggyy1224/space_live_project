# Status: pending
# Dependencies: 1, 4

# Description: Implement various tool nodes in LangGraph for content generation and external API integration using an MVP approach with phased milestones.
# Details:
Create a set of tool nodes within LangGraph using an incremental MVP development approach:

**Milestone 1: Core Content Generation (MVP)**
- Implement `StoryGenerationNode` for simple sci-fi stories
- Create `GreetingGenerationNode` for basic opening rituals
- Focus on minimal viable functionality with simple prompts
- Ensure integration with LangGraph core (Task 1)

**Milestone 2: Basic External Services**
- Implement `NewsFetchingTool` for space and science news using a simple reliable API
- Create `WeatherRetrievalTool` with minimal functionality
- Develop `ImageDisplayNode` for showing content
- Integrate with scheduling nodes (Task 4) to enable basic broadcast functionality

**Milestone 3: Expanded Functionality**
- Add `DiaryGenerationNode` for AI diary entries
- Implement `AIImageGenerationTool` for simple image generation
- Create `MusicPlaybackTool` for theme songs
- Develop additional tools based on priority needs

**Implementation Guidelines:**
- Use simple, reliable APIs and services
- Implement minimal feature set for each tool node
- Ensure each milestone delivers demonstrable functionality
- Prioritize integration with core system over complex features
- Defer complex error handling and fallback mechanisms
- Focus on functional implementation rather than extensive testing

Ensure close coordination with Task 1 (LangGraph Core) and Task 4 (Scheduling Nodes) to guarantee tool nodes can be properly utilized within broadcast periods.
