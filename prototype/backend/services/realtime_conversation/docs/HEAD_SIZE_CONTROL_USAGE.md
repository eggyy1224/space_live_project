# 頭部大小控制功能使用指南

## 📏 功能概述

頭部大小控制 (head_size_control) 是 realtime conversation 系統的最新功能，允許 AI 角色在對話過程中動態調整頭部模型的縮放比例，創造豐富的視覺效果和情感表達。

## 🎯 主要用途

### 情感表達增強
- **驚訝時刻**：放大頭部強調驚訝感
- **害羞內向**：縮小頭部表達羞澀
- **自信展現**：適度放大表現自信
- **思考狀態**：微縮頭部顯示專注

### 搞笑效果
- **喜劇時刻**：誇張放大創造幽默感
- **俏皮互動**：配合台語 English 風格
- **意外反應**：突然縮放增加趣味

### 強調重點
- **重要信息**：放大頭部吸引注意
- **關鍵時刻**：配合表情和音效
- **高潮起伏**：營造對話節奏感

## 📐 縮放範圍說明

### 極小範圍 (1 - 6)
```
1 ～ 3：極度微小，營造超可愛或極度害羞效果
4 ～ 6：顯著縮小，表達害羞、謙虛或安靜時刻
```

### 縮小範圍 (7 - 10)
```
7 ～ 8：輕度縮小，適合思考或專注狀態
9 ～ 10：微縮，表達冷靜或沉思
```

### 正常範圍 (11 - 14) ⭐ 推薦
```
11 ～ 12：接近正常，日常對話基準
12 ～ 13：標準大小，大部分情況使用 ⭐
14：微放大，表達輕度興奮或自信
```

### 放大範圍 (15 - 17)
```
15 ～ 16：明顯放大，適合驚訝或強調
17：顯著放大，營造興奮或震驚效果
```

### 極大範圍 (18 - 20)
```
18 ～ 19：誇張放大，喜劇效果
20：極度誇張，特殊情境或超強調
```

- play_audio: 馬喘息聲.mp3

```

### 情境 3：強調重點
```

AI 回應：

### 情境 4：恢復正常
```
完成特殊效果後：

- emotion_trajectory: content → neutral
- 繼續對話...
```

### 情境 5：日常對話
```
一般聊天時：

- emotion_trajectory: neutral → interested → content
- 自然對話...
```

## ⚡ 使用原則

### 主動使用策略
1. **情境驅動**：根據對話內容自動判斷使用時機
2. **情感配合**：與表情動畫和音效完美結合
3. **節奏掌控**：適時變化，避免過度頻繁
4. **回歸平衡**：記得適時回到正常大小

### 組合使用技巧
```python
# 完美三重組合
head_size_control(縮放因子)     # 頭部大小
emotion_trajectory(表情變化)   # 豐富表情
play_audio(音效檔案)          # 角色音效

# 可選搭配
background_audio(背景音樂)     # 環境氛圍
camera_control(鏡位變化)      # 視角切換
```

## 🚀 使用建議

### 最佳實踐
1. **適度使用**：不要每句話都變化
2. **情境合理**：確保縮放符合情感表達
3. **組合效果**：結合表情、音效使用
4. **用戶體驗**：避免過於劇烈的變化

### 注意事項
- 記得在特殊效果後回到正常大小 (12-13)
- 配合其他工具使用效果更佳
- 考慮用戶的視覺接受度
- 保持角色的一致性和可愛感
- 大部分情況保持在 12-13 範圍，特殊情況才使用極值
