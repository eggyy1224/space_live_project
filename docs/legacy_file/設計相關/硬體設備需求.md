# Space Live 展場硬體規格（雙螢幕版本）

> 更新日期：2025‑05‑19。以下為最小可運行配置，所有項目可因場地或預算微調。
> 

---

## 系統連接概覽（快速查看）

```
Mac mini
 ├─ HDMI          -> 橫向 16:9 螢幕（動畫主視覺）
 ├─ USB‑C -> HDMI -> 直向  9:16 螢幕（聊天室 / UI）
 ├─ USB‑A         -> USB 指向性麥克風
 ├─ USB‑A         -> 熱感印表機 (或 Powered USB Hub)
 └─ Thunderbolt   -> ※ 預留 1 埠 (高速外設 / 第三顯示)

攝影機 A (HDMI) --> 擷取卡 --> Mac mini
攝影機 B (USB or RTMP) --> 直播服務
```

---

## 1 主控電腦

| 項目 | 規格建議 | 備註 |
| --- | --- | --- |
| 型號 | **Mac mini (M2, 8‑core)** 或同級以上 | — |
| 記憶體 | ≥ 16 GB RAM | — |
| 儲存 | ≥ 512 GB SSD | — |
| 連接埠 | Thunderbolt/USB‑C × 2、USB‑A × 2、HDMI × 1 | — |
| 網路 | Wi‑Fi 6、Gigabit Ethernet | — |

## 2 顯示系統

### 2‑A 橫向螢幕（主視覺）

| 規格建議 |  |
| --- | --- |
| 尺寸 | 55–65 吋、16∶9 |
| 解析度 | 4K UHD (3840 × 2160) |
| 亮度 | ≥ 500 nits |
| 等級 | 商用 24/7 運行 |
| 介面 | HDMI 2.0 |
| 安裝 | VESA 掛牆或落地支架 |

### 2‑B 直向螢幕（聊天室 / UI）

| 規格建議 |  |
| --- | --- |
| 尺寸 | 50–55 吋、9∶16 |
| 解析度 | 4K UHD (2160 × 3840)＊Full HD 亦可 |
| 亮度 | ≥ 500 nits |
| Portrait Mode | 支援自動旋轉 |
| 介面 | HDMI 2.0（USB‑C→HDMI 轉接） |
| 安裝 | 直立支架或壁掛，確保散熱與穩固 |

## 3 影像輸入（攝影機）

| 分類 | 規格建議 | 配件 |
| --- | --- | --- |
| **攝影機 A**（觀眾／環境） | 1080p 60 fps、HDMI Clean‑Out | HDMI 擷取卡 |
| **攝影機 B**（直播） | 1080p 30 fps USB Cam / All‑in‑One（RTMP 推流） | — |
| 通用 | 三腳架 × 2 | — |

## 4 音訊系統

| 項目 | 規格建議 |
| --- | --- |
| 收音 | USB 指向性麥克風（心／超心形），48 kHz / 24‑bit |
| 擴音 | 主動式 2.0 監聽喇叭，一對；單聲道 ≥ 30 W RMS |

## 5 實體輸出

| 項目 | 規格建議 | 備註 |
| --- | --- | --- |
| 熱感印表機 | 58 mm 或 80 mm（USB），列速 ≥ 100 mm/s | 即時列印角色文字／圖像 |

## 6 網路

| 項目 | 規格建議 |
| --- | --- |
| 上傳頻寬 | 有線 ≥ 100 Mbps（推流＋遠端管理） |

## 7 電源與備援

| 項目 | 規格建議 |
| --- | --- |
| 供電 | 110 V / 10 A 獨立迴路 |
| UPS | 500 W（Mac mini + 兩台螢幕） |
| 智慧電源 | 支援遠端重啟的 Smart Plug 或 PDU |

## 8 周邊配件

- USB‑C → HDMI 2.0 轉接器 × 1（直向螢幕）
- 高速 HDMI 2.0 線 × 2（4K60，依距離選長度）
- Powered USB Hub × 1
- 三腳架／燈腳 × 3（含備用）
- 走線與收納：魔鬼氈、走線槽等

---

### 備註

1. **雙 4K60 顯示**：Mac mini M2 原生支援，可保留 1 組 Thunderbolt 作擴充。
2. **亮度**：一般藝廊 500 nits 已足；光害高時建議升級 700 nits 以上面板。
3. **Portrait 散熱**：直立螢幕需預留背部通風並確保支架配重穩固。
