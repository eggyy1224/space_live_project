# 一、固定直播任務的時段內容（每日 6 小時結構）

虛擬網紅每日直播分為六大時段，結合資訊播報、情緒演出、觀眾互動與創作展演，支撐長期觀看與創造習慣黏著性：

| 時段    | 模組名稱               | 內容細節                                                               |
| ------- | ---------------------- | ---------------------------------------------------------------------- |
| 第1小時 | 太空早報｜開場儀式     | 播報即時衛星雲圖、太空中心新聞；設定當日任務照主題，開場打招呼儀式     |
| 第2小時 | 肢體演出｜互動動作時段 | 無重力舞蹈、表情挑戰、太空瑜伽、觀眾點播動作演出                         |
| 第3小時 | 幻想投影｜夢境劇場     | AI生成太空幻想背景，結合敘事與感官演出（夢境冥想、幻象互動）           |
| 第4小時 | 主題演出｜科幻故事＋唱歌 | 表演一段微型科幻劇（自創或從當日資料生成）＋唱主題曲或觀眾選曲         |
| 第5小時 | 觀眾互動｜留言模仿＋回應 | 唸留言、模仿觀眾表情、即時互動QA，選一句觀眾語錄存入記憶               |
| 第6小時 | 記憶日誌｜晚安儀式     | 朗讀今日AI日記、展示任務照片、播放晚安曲，進入虛擬休眠                 |

# 二、情緒記憶累積與體態造型變化系統

目標是打造一位能累積全年記憶、情緒、互動經驗的虛擬生命體，並透過這些內在變化影響她的外在造型與表演風格：

## 1. 記憶層級系統（不重置、全年累積）

| 層級     | 內容                           | 功能                                     |
| -------- | ------------------------------ | ---------------------------------------- |
| 短期記憶 | 每日情緒變動、事件摘要、任務照 | 即時影響表現情緒、背景色、小裝飾         |
| 中期記憶 | 每週挑選高情緒值事件生成節點   | 形成主線事件，逐漸推動造型變化           |
| 長期記憶 | 52週記憶節點編年牆、語錄牆     | 構成年度自傳式生命軌跡，可剪輯回顧影片 |

## 2. 情緒與造型連動設計（持續演化）

情緒如：喜悅、焦慮、孤獨、驕傲等會逐漸塑造身體語言、裝飾紋理、色彩調性。

**所有變化都是「疊加式成長」，而非月更重置。**

### 造型特徵模組例如：

*   **喜悅多** → 輕盈光感／透明紋理
*   **焦慮多** → 銳利感官／偵測裝置
*   **留言互動多** → 背後浮現語錄星河

她最終會在年底成為一個獨特個體，其造型是由觀眾互動＋情緒歷程共同生成。

---

這兩個系統是互補的：

*   **每日直播結構** 是「可持續執行的日常框架」
*   **情緒記憶系統** 是「讓她在這些日常中成長為一個更像人的存在」

# 功能許願：Space live 核心功能總表（簡明版）

| 功能分類         | 子功能           | 說明                                                       |
| ---------------- | ---------------- | ---------------------------------------------------------- |
| **1. 每日直播排程** | 六小時分段內容   | 固定直播流程（早報、動作、幻想、故事、互動、日誌）         |
|                  | 主題切換功能     | 每天可指定不同主題日（如幻想日、演出日）                   |
|                  | 資訊串流         | 串接即時太空新聞、衛星雲圖等公開資料                       |
| **2. 表演與互動**   | 表情控制         | 可調整喜怒哀樂等情緒動畫                                   |
|                  | 肢體動作         | 支援舞蹈、伸展、指定姿勢等表現                             |
|                  | 唱歌演出         | 可播放虛擬人演唱，支援字幕或語音生成                       |
|                  | 科幻故事演出     | 根據資料或觀眾互動生成短劇，進行單人演繹                   |
|                  | 觀眾留言互動     | 可回應留言、唸出觀眾訊息、模仿表情動作                     |
| **3. 自拍與圖像創作** | 每日自拍任務     | 系統生成當日姿勢／主題，自動拍照與儲存                     |
|                  | 自拍合成特效     | 根據情緒／主題加上濾鏡、光影或AI背景                       |
|                  | 照片記憶牆       | 收藏並分類所有自拍，形成可視化生命軌跡                     |
| **4. 情緒與記憶系統** | 情緒偵測         | 分析觀眾留言、新聞事件與任務結果產生情緒值               |
|                  | 記憶累積         | 記錄每日重要事件與情緒，逐週形成記憶節點                   |
|                  | 全年記憶不中斷   | 所有變化持續疊加，形成人格與行為演化                       |
| **5. 造型與身體變化** | 情緒驅動造型     | 長期情緒變化將影響髮色、紋理、光影等外觀特徵               |
|                  | 特殊事件反應     | 特定事件觸發劇烈外觀轉變（如停播、生日）                   |
| **6. 觀眾參與擴充** | 投票系統         | 觀眾可決定表演方向、記憶保留、造型分支等                 |
|                  | 語錄收藏         | 被記住的留言會出現在記憶牆，影響未來行為                   |
