## 實施策略

重構應採用漸進式方法，但考慮到前端需求的優先性，建議以下實施順序：

1. **階段一**: 優先改進前端介面，添加歌曲庫和增強 Freesound 整合，提供可用的工作界面
2. **階段二**: 實現聲音分類系統和雙管線基本架構，明確區分需要表情的聲音與純音效
3. **階段三**: 實現簡化版的時間軸功能，支援基本的音效排程
4. **階段四**: 逐步引入核心架構，包括 AudioTimeline 和協調器
5. **階段五**: 整合語音與音效系統，實現統一管線
6. **階段六**: 完善資源管理和進階功能

## 下一步優先任務

1. 將「預設音效」頁籤改造為「歌曲庫」，設計和實現歌曲播放功能

4. 設計簡單的時間軸編輯器，支援基本的音效排程
