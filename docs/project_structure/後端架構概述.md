# 後端架構概述

本文檔概述虛擬太空人互動藝術裝置專案的後端架構，包含核心技術、目錄結構、API 路由、資料模型與服務協調器等關鍵資訊。

## 核心技術

虛擬太空人後端採用現代化技術棧，主要包含：

- **FastAPI**: 高效能 Python Web 框架，提供非同步處理能力與自動 API 文檔生成
- **LangChain/LangGraph**: AI 語言模型整合與工作流程框架，用於構建對話系統
- **ChromaDB**: 向量資料庫，用於語義搜尋與記憶系統實現
- **WebSocket**: 即時雙向通訊，實現前後端即時互動
- **Google Gemini**: AI 大型語言模型，提供自然語言理解與生成能力
- **Google Cloud Speech-to-Text**: 語音轉文字服務，處理用戶語音輸入
- **Google Cloud Text-to-Speech**: 文字轉語音服務，生成虛擬太空人語音
- **PostgreSQL/pgvector**: 關聯式資料庫與向量擴展，用於持久化儲存
- **Uvicorn**: ASGI 伺服器，提供高效能的異步服務
- **Pydantic**: 資料驗證與序列化，確保 API 資料完整性

## WebSocket 通訊協定

WebSocket 端點是系統的核心通訊管道，處理前端發送的用戶訊息，並即時回傳虛擬太空人的回應、情緒狀態與動作指令。

### 主要功能
- **即時對話處理**: 接收用戶訊息，透過 AI 服務生成回應
- **語音播放握手機制**: 確保語音播放順序，前端回傳 `playback_ack` 後才傳送下一段音頻
- **狀態同步**: 同步虛擬太空人的情緒、動作、表情等狀態
- **自言自語管理**: 在閒置時間觸發自發性言論
- **連接管理**: 處理多個客戶端連接，支援廣播訊息

### 訊息類型
- **user_message**: 用戶輸入訊息
- **ai_response**: AI 生成的回應
- **emotion_update**: 情緒狀態更新
- **animation_trigger**: 動畫觸發指令
- **playback_ack**: 語音播放確認
- **system_status**: 系統狀態更新
- **camera-angle**: 攝影機角度控制
- **camera-transition**: 攝影機平滑轉換
- **body-animation**: 身體動畫控制
- **head-size**: 頭部大小控制
- **scene-display**: 場景顯示控制

## 效能優化與資源管理

- **WebSocket 資料壓縮**: 減少網路傳輸量，提升即時通訊效能
- **記憶快取機制**: 使用向量資料庫快取常用記憶，減少查詢延遲
- **定期清理過期檔案**: 自動管理 debug_audio 與 generated_images 目錄
- **API 使用配額管理**: 控制 Google API 呼叫頻率與數量
- **資源使用監控**: 記錄系統資源使用情況，及時發現潛在問題
- **靜態檔案優化**: 支援多種音訊格式與 CORS 標頭優化
